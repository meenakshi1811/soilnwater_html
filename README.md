# SoilNWater

Community and marketplace platform built with Laravel 12, Vite, Bootstrap, and MySQL.

## Development

See **[DEVELOPMENT.md](DEVELOPMENT.md)** for full setup instructions.

**Quick start (Windows / XAMPP):**

```powershell
.\scripts\setup-dev.ps1
```

Then open **http://localhost/soilNwater/public** with XAMPP Apache and MySQL running.

**Dev server with hot reload:**

```powershell
.\scripts\dev.ps1
```

## Tech Stack

- **Backend:** PHP 8.2+, Laravel 12
- **Frontend:** Vite 7, Bootstrap 5, Sass
- **Database:** MySQL
- **Realtime:** Laravel Reverb
- **Auth:** Laravel UI, Google OAuth (Socialite)
- **Permissions:** Spatie Laravel Permission
